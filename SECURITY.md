# Credential examples

Published notes use inert placeholders for provider keys and private key material.
Obtain temporary credentials and artifacts from an authorized lab; keep personal
and production credentials outside this repository. Methods remain documented,
but a copied credential should never be treated as a reusable learning resource.

Run `python tools/check_credential_examples.py` before publishing note changes.
The check reports only path, line and category. It is a focused guard for these
examples, not a complete secret or personal-data scanner.

Current-file redaction does not remove earlier commits, cached copies or forks.
Previously published examples have not been used to authenticate to providers,
and their validity and ownership are unverified. Owners of any real credential
must revoke or rotate it; history cleanup needs a coordinated repository rewrite.
